# my-energy-band-culculate-way-one
A Python script to plot VASP band structure from EIGENVAL and OUTCAR (without SOC).

## Features
- Read EIGENVAL and OUTCAR from VASP calculation
- Plot band structure
- No SOC support

## Usage
1. Prepare your VASP output files (EIGENVAL, OUTCAR)
2. Run the script
```bash
python plot_band.py
